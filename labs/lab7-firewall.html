Firewall

A network security system

It monitors and controls incoming and outgoing traffic, protecting the internal network. Grey packets get checked at the wall: green passes, red is blocked.

What it does

Monitors and controls IN and OUT network traffic using rules, and protects the systems behind it.

Types

Hardware firewalls sit at the network edge. Software firewalls run on the host itself.

HardwareSoftware
iptables

The Linux firewall utility we use in the lab. Its rules are grouped into chains: INPUT, OUTPUT and FORWARD.

iptables chains on one host

Set each chain's policy below and watch the traffic change. The dashed orange lines are where iptables checks each packet.

INPUT

Packets coming in, addressed to this host.

OUTPUT

Packets created on this host going out.

FORWARD

Packets passing through the host, routed from one network to another.
