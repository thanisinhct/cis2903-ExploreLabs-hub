Blocking SSH with iptables

    Linux terminal Ubuntu VM
    
      
    Windows cmd Run → cmd
    
    
    
  
    

  
    
    
    Be root first
    Run iptables commands as root.
    Switch with su - or sudo -i. The prompt changes from $ to #.
    
    
    Configure iptables
    iptables is installed by default.
    Back up: iptables-save > tables.backup
    List: iptables -L
    Delete: iptables -D INPUT 3
    
    
    From Windows cmd
    ssh -p 2222 cis@192.168.16.7
    scp -P 2222 testfile.txt cis@192.168.16.7:
    sftp -P 2222 cis@192.168.16.7
    
    
    
      
      
    Very, very important: read the question carefully and understand the rule before executing it.
    
      
    iptables -A INPUT -p tcp --dport 2222 -j DROP drops only incoming TCP traffic on port 2222. Everything else still gets through.
    
    
    
    
    Syntax to watch
      
      
        
    • Chain names are uppercase: INPUT, not input. Lowercase fails with “No chain/target/match by that name”.
      • 
        
    • -D needs the chain and the number: iptables -D INPUT 3. Use iptables -L --line-numbers to see the numbers.
      • 
        
    • ssh takes a lowercase -p for the port; scp and sftp take a capital -P.
      • 
        
    • scp needs a colon after the host (cis@192.168.16.7:). Without it, scp copies to a local file named after the host.
