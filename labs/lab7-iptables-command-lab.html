-F keeps the policyFlushing removes the rules but not the default policies. If INPUT is set to DROP and you flush, all incoming traffic is blocked, including your own SSH session.

      
Real servers: allow repliesWith INPUT on DROP, replies to the host's own outgoing requests are dropped too. Real setups add iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT first. This lab tests new connections only.

      
Rule numbersiptables -L --line-numbers shows the number to use with -D. Numbers shift up after a delete.

      
Names vs numbers-L shows port names (ssh, http). Add -n to see numbers (dpt:22, dpt:80).
